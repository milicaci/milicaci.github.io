КЕЙС 01 · API И АВТОМАТИЗАЦИЯ

Сбор данных Wildberries и Ozon

Python · REST API · Pandas · Google Apps Script

Автоматизация

Задача

Собирать данные маркетплейсов из нескольких источников, приводить их к общей структуре и подготавливать к регулярной отчётности.

Что делала

  • Работала с API и отчётными файлами Wildberries и Ozon.
  • Писала и исправляла Python-скрипты для загрузки и обработки данных.
  • Приводила поля к единому формату, проверяла дубли и ошибки.
  • Использовала Apps Script для обновления таблиц и сохранения истории.

Результат

Подготовленный поток данных для отчётов и меньше повторяющихся ручных операций. Точное сокращение времени для этого кейса не заявляется.

КЕЙС 03 · АНАЛИТИЧЕСКИЙ ОТЧЁТ

Финансовая аналитика Wildberries в Power BI

Power BI · Power Query · DAX · PostgreSQL

Отчёт

Задача

Создать отчёт, в котором можно анализировать выручку, расходы, рентабельность и динамику продаж по товарам и периодам.

Что делала

  • Подключала источники и подготавливала данные в Power Query.
  • Строила модель данных, создавала меры DAX и визуализации.
  • Использовала отчёты WB из PostgreSQL и справочники из Google Sheets.
  • Проверяла расчёты, выявляла повторы заказов и пропуски себестоимости.

Результат

Интерактивный отчёт для первичной оценки финансовых показателей с обозначенными ограничениями качества данных.
